Install the preview

Aim is on the Chrome Web Store. Install it from there to get updates automatically.

Add to Chrome, free

Aim is coming to the Chrome Web Store. Until then, you can install the preview by hand. It takes about a minute, on a computer, in Chrome, Edge or Brave.

  1. Download the preview. aim-preview.zip
  2. Unzip it into a folder you'll keep, such as Documents/Aim. Chrome runs Aim from that folder, so don't delete it.
  3. Open your browser's extensions page. Type chrome://extensions into the address bar (in Edge, edge://extensions; in Brave, brave://extensions).
  4. Turn on Developer mode (a switch at the top right, or bottom left in Edge).
  5. Click Load unpacked and choose the unzipped folder, the one with manifest.json inside.
  6. Aim opens and says hello. Pin it: the puzzle piece in the toolbar, then the pin next to Aim.

Updating: download the new preview, replace the folder's contents, and click the reload arrow on Aim's card in the extensions page. Your aims and settings stay. Chrome may remind you that a developer-mode extension is on; that's expected for a preview.
