# Scenes

The pictures behind Aim's homepage on YouTube and Aim's own pages (0.73, the reading room).

| File | Where |
|---|---|
| `home.jpg` | YouTube's homepage: Home, Continue Learning, the Daily and Weekly Challenges |
| `break.jpg` | YouTube's homepage: Break |
| `library.jpg` | Aim's pages (the Library clearest, darker behind Settings and the rest) |
| `subjects/<subject>.jpg` | A subject's tile in the Library and a path's picture in Continue Learning. Subject ids are `SUBJECTS` in store.js; a subject without a picture shows its engraved emblem (covers.js) |

They come from the owner's own design mockups (November 2026), with the interface painted out of
the middle of each scene; the middle sits under Aim's panels, so it's left soft on purpose. To use
cleaner versions, replace a file with one of the same name: about 1700×950 or larger for the scenes,
about 2:1 for subjects, JPEG. Only pictures the project owns or has a license for go here.
